# Face Generation with a DCGAN

A Deep Convolutional GAN trained on the CelebA dataset to generate novel human
faces, implemented in PyTorch (generator, discriminator, adversarial training
loop, and weight initialization).

Project of Udacity's Deep Learning Nanodegree (2019). Archived as a learning
milestone.

**Demonstrates:** GAN training dynamics, transposed-convolution generators,
batch normalization, and the practical instabilities of adversarial training.
